# نور — قصص وأخلاق من القرآن · Нур

قصص مصوّرة تفاعلية للأطفال (٥–١٠ سنوات): يقرأ الطفل الموقف، **يختار تصرّفه**، ثم **يقارن اختياره بالقرآن الكريم**، ثم يتعلّم لماذا، ويلوّن، ويتدرّب، ويطبّق مهمة لمدة ٧ أيام.

هذه نسخة تجريبية بقصة واحدة: **«البرج الذي سقط»** (كظم الغيظ والعفو — آل عمران ١٣٤)، بنسختين:

| النسخة | الرابط | الجمهور | الشخصيات |
|---|---|---|---|
| العربية | `ar/index.html` | الأطفال العرب المسلمون | عمر وأمينة — بيت عربي |
| الروسية | `ru/index.html` | الأطفال المسلمون في روسيا | تيمور وعليّة — بيت تتري في قازان |

## خطوات الدرس

1. **القصة** — ٧ لوحات تظهر واحدة تلو الأخرى.
2. **اختر** — مشهدان: أيّهما تختار لو كنت مكانه؟
3. **قارن بالقرآن** — الآية بجانب اختيار الطفل، مع حكم لطيف (يوافق / لا يوافق ← اختر مرة أخرى).
4. **لماذا؟** — الآية كاملة مع إبراز الجزء المقصود، تلاوة الشيخ مشاري العفاسي، المعنى، كلمات الآية، أسباب من القرآن والسنة مع مصادرها.
5. **لوّن** — تلوين الاختيار الصحيح بألوان زاهية والآخر بالرمادي (مع طباعة).
6. **تدرّب** — لعبة ✓ / ✗.
7. **مهمّتي** — ٧ أيام، ثم نجمة.

و**ركن الوالدين** في الصفحة الرئيسية يُظهر هل اختار الطفل الصواب من أول مرة، مع أسئلة للحوار.

## المصادر

- نص الآية: الرسم العثماني برواية حفص (من quran.com عبر quran.ai).
- الترجمة الروسية: Эльмир Кулиев — «Священный Коран. Смысловой перевод».
- التفسير: «التفسير الميسّر» (مجمع الملك فهد). الشرح الروسي ترجمتنا له ومذكور ذلك في الصفحة.
- الأحاديث: البخاري ومسلم وأبو داود، بصياغة مبسّطة للأطفال، مع ذكر المصدر.
- التلاوة: الشيخ مشاري العفاسي (everyayah.com).

> يُنصح بمراجعة النصوص الشرعية مع معلّم موثوق قبل النشر التجاري.

## الرسومات

الرسومات غير موجودة بعد. كل صورة مطلوبة موصوفة بدقة مع أمر التوليد في **[ART-BRIEF.md](ART-BRIEF.md)**.
ضع الصور في `images/ar/` و`images/ru/` بالأسماء المذكورة، وتظهر تلقائيًا. حتى ذلك الحين يظهر إطار «الرسم قيد الإعداد».

## التشغيل

مشروع ثابت بلا أي بناء (HTML + CSS + JavaScript). للتلوين يجب فتحه من خادم (وليس بالنقر المزدوج على الملف):

```bash
cd nur-stories
python3 -m http.server 8000
```

ثم افتح http://localhost:8000 . يمكن رفعه كما هو على GitHub Pages أو Netlify.

## بنية المشروع

```
nur-stories/
├── index.html          اختيار النسخة (عربي / روسي)
├── ar/index.html       النسخة العربية
├── ru/index.html       النسخة الروسية
├── data/ar.js          كل نصوص النسخة العربية (القصة، الآية، الأسباب، التمرين…)
├── data/ru.js          كل نصوص النسخة الروسية
├── js/app.js           محرّك الدرس (مشترك بين النسختين)
├── css/style.css       التصميم
├── images/ar, images/ru   الرسومات
└── ART-BRIEF.md        وصف كل رسمة + أوامر التوليد
```

لإضافة نسخة/لغة جديدة: انسخ `data/ru.js` وترجم النصوص، وأنشئ صفحة مثل `ru/index.html` تحمّل الملف الجديد.
